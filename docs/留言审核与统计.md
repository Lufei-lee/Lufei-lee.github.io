# 留言审核与每日访客 / Moderation and daily visitors

入口保持 Cloudflare 登录保护，不在公开网站增加管理权限。
Open [Cloudflare D1 Studio](https://dash.cloudflare.com/accac395ad886d225f1660a1956b8751/workers/d1/databases/573d8668-71ba-4300-a636-deea6bc77578/studio).

## 留言管理 / Manage messages

新版留言与回复提交后立即公开，点赞即时生效，无需预审核。前台成功提示为“留言成功！谢谢你的留言！”。
Messages and replies publish immediately; likes take effect immediately.

在 Studio 的 Query 标签执行下面的只读查询，按北京时间查看内容、状态和原留言编号：

```sql
SELECT m.id, m.name, m.message, datetime(m.created_at,'+8 hours') AS beijing_time,
       m.status, r.parent_id AS root_id, t.target_id AS reply_to
FROM messages m
LEFT JOIN message_replies r ON r.message_id=m.id
LEFT JOIN reply_targets t ON t.message_id=m.id
ORDER BY m.created_at DESC;
```

在 messages 表按完整 id 筛选后修改 status：`approved` 公开，`rejected` 隐藏。隐藏主留言会隐藏整个对话；隐藏某条回复只隐藏该条，后续对话保留，回复对象显示“已隐藏或删除的留言”。恢复为 approved 即可重新公开。

也可逐条运行（先替换编号，始终保留 WHERE）：

```sql
UPDATE messages SET status='rejected' WHERE id='填写完整留言编号';
```

如需永久删除，在 messages 表选择该行 Delete；也可运行：

```sql
DELETE FROM messages WHERE id='填写完整留言编号';
```

删除主留言会连同其所有回复和点赞清理；只删除回复时，后续对话仍保留，回复对象置空。永久删除无法通过修改状态恢复，想保留恢复能力请使用隐藏。没有新增公开管理端点或管理员密码。

回复默认隐藏，主留言操作区显示“回复 · 数量”。每次展开最新5条（同一时间按编号稳定排序），可继续每次展开5条或全部收起。每条回复也能继续回复，所有对话平铺在原留言下并标注回复对象。点击回复后自动滚动并聚焦顶部输入区。

Keep the existing authenticated Cloudflare Studio entry. Set status to rejected to hide, or approved to restore. Deleting a root deletes the whole conversation; deleting one reply preserves later responses with an unavailable-target label. Replies start collapsed and reveal five more per click, newest first. Every reply can be answered from the form above.

## 每日 UV / Daily unique browsers
在同一个 Query 标签执行：

```sql
SELECT day AS beijing_date, COUNT(*) AS unique_browsers
FROM daily_visitors GROUP BY day ORDER BY day DESC LIMIT 90;
```

日期由服务器按北京时间确定；同一浏览器当天反复刷新、切换文章只计一次。数据库保存按日期变化的 HMAC，不保存原始浏览器标识或 IP。统计没有公开读取接口，只在已有 Cloudflare 登录后查看。

这是独立浏览器数，不是精确人数：换浏览器、无痕模式或清除存储会重新计数。禁止本地存储或开启 Do Not Track 时不采集本项；网络/拦截器可能造成漏计。没有验证码，不能防止有意伪造浏览器标识；端点有限流。新指标只从新版上线时积累，无法回填历史。

GoatCounter 继续提供各页面访问、来源和设备统计，沿用其原有会话去重规则；不可将其中 visits 与这里的每日 UV 混为同一指标。文章间路径变化会计数，目录锚点跳转不计数。统计读取权限保持私有。

Daily UV means unique browsers per Beijing calendar day, not identified people. New browsers/private sessions/reset storage count separately; network blocking may undercount. Collection honors Do Not Track and requires persistent browser storage. GoatCounter page visits retain their own session rules. Neither measure retroactively repairs historical data.
